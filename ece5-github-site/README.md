# ECE 5 GitHub Pages project website

A static website for showing **three code files and two images**.

## Upload the following files

Make sure your GitHub repository has this structure (exact spelling and capitalization):

```
index.html
code/
  potentiometer.ino
  photoresistor.ino
  project3.ino
images/
  photo1.jpg
  photo2.jpg
```

The example code and image file paths in `index.html` assume the exact names above.
Rename your existing files when uploading, or edit `index.html` to reflect your actual names and extensions (e.g. `.png` instead of `.jpg`).

`project3.ino` is just a placeholder filename for your real third code file. This package does not include your code or images: put your actual files in those directories.

## Deploy to GitHub Pages

1. Open your `xiaoming12gh.github.io` repository.
2. Upload `index.html` at the repo root, and create/upload `code/` and `images/` with your files.
3. Settings -> Pages -> Build and deployment -> Deploy from a branch -> `main` -> `/(root)`.
4. Visit https://xiaoming12gh.github.io/ after deployment.
